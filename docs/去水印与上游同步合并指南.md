## 二、3 处具体改动点与代码对比

### 1. 水印图层总开关置为 `false`（约第 404 行）

* **函数位置**：`fun MainScreen(fragmentActivity: FragmentActivity)`
* **上游原代码**：
  ```kotlin
  val showPiracyTiles = (
      LocalContext.current.applicationInfo.flags and
          ApplicationInfo.FLAG_DEBUGGABLE
      ) != 0 && !BuildConfig.UI_PREVIEW
  ```
* **修改后代码**：
  ```kotlin
  val showPiracyTiles = false
  ```
* **作用**：彻底关闭顶层水印图层的加载，使 Compose 界面树不再挂载平铺水印容器。

---

### 2. 清空右下角“开源版 · 请勿商用”微型角标（约第 740 行）

* **函数位置**：`private fun BoxScope.AppBuildWatermarks()`
* **上游原代码**：
  ```kotlin
  @Composable
  private fun BoxScope.AppBuildWatermarks() {
      Text(
          text = "开源版 · 请勿商用",
          modifier = Modifier
              .align(Alignment.BottomEnd)
              .padding(end = 12.dp, bottom = 8.dp),
          color = MaterialTheme.colorScheme.onSurfaceVariant.copy(alpha = 0.55f),
          fontSize = 10.sp,
          fontWeight = FontWeight.Medium
      )
  }
  ```
* **修改后代码**（直接清空函数体）：
  ```kotlin
  @Composable
  private fun BoxScope.AppBuildWatermarks() {
  }
  ```
* **作用**：不再在主屏幕右下角渲染小字提示。

---

### 3. 屏蔽“开源版 / 严禁倒卖”满屏斜排平铺绘制（约第 745 行）

* **函数位置**：`private fun Modifier.debugPiracyWatermark`
* **上游原代码**：
  包含利用 `Picture`、`drawText("开源版 / 严禁倒卖", ...)`、旋转 -28° 进行两层网格循环平铺绘制的大段逻辑。
* **修改后代码**（直接返回 `this`）：
  ```kotlin
  private fun Modifier.debugPiracyWatermark(enabled: Boolean): Modifier = this
  ```
* **作用**：完全不分配 `Picture` 录制画布，不执行任何平铺文字绘制。

---

## 三、未来同步上游时解决冲突的操作流程

当从上游拉取更新并合并到 `dev` 分支时（例如 `git merge main`）：

1. **若提示 `MainActivity.kt` 发生冲突**：
   打开 [`app/src/main/java/com/tyust/course/MainActivity.kt`](file:///c:/Users/Emoing/Desktop/zhengfang-apk/app/src/main/java/com/tyust/course/MainActivity.kt)。

2. **定位冲突标记**：
   在搜索到 `<<<<<<< HEAD` 与 `>>>>>>>` 时：
   - 找到 `showPiracyTiles`，保留 `val showPiracyTiles = false`；
   - 找到 `AppBuildWatermarks()`，保持函数体为空；
   - 找到 `debugPiracyWatermark`，保留 `private fun Modifier.debugPiracyWatermark(enabled: Boolean): Modifier = this`。

3. **保存并完成合并**：
   ```bash
   git add app/src/main/java/com/tyust/course/MainActivity.kt
   git commit -m "Merge upstream and keep watermarks disabled"
   ```

4. **重新打包验证**：
   ```bash
   ./gradlew assembleDebug
   ```
